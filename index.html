문제 해결

대량조회 누락 → 해결

14일치를 한 번에 조회하면 데이터를 다 못 받아오는 문제가 있었습니다. 4일씩 나눠서 조회하고 중복만 제거하는 방식으로 바꿔서 전부 정상 수집되게 했습니다.

요청 제한 초과 → 해결

한 번에 너무 많이 요청하면 막히는 문제가 있었는데, 요청 간격을 조절하고 실패하면 자동으로 다시 시도하게 만들어 15만 건이 넘는 데이터도 누락 없이 수집했습니다.

로그인 정보 만료 → 해결

로그인 정보가 2주마다 만료되는 문제를, 하루 2번 자동 갱신하도록 만들어서 사람이 다시 로그인하지 않아도 되게 했습니다.

시트 데이터 밀림 → 해결

시트에 열이 하나 추가되면서 데이터가 밀려 잘못 들어가는 문제를 발견해 고치고, 빠진 날짜 데이터도 다시 채워 넣었습니다.

조용한 실패 → 감지 체계

KPI 자동 기입 스크립트가 시트 범위를 고정해 둔 탓에, 시트가 길어지자 아무것도 못 쓰면서도 오류 없이 매일 정상 종료됐습니다. 몇 주간 모르고 지나간 뒤 발견해서, 고정 범위를 탐색 방식으로 바꾸고 실패하면 반드시 알림이 오도록 고쳤습니다.

자동화 충돌 → 주체 일원화

"켜둔 광고가 자꾸 꺼진다"는 현상을 추적해 보니, 매체사 자체 자동 규칙과 제가 만든 스크립트가 서로 다른 기준으로 동시에 돌고 있었습니다. 전수 조사로 잘못 꺼진 건을 찾아 되살리고, 자동 조치 주체를 한쪽으로 정리했습니다.

더 자세한 역량은 상단 메뉴 — 기획력 · 바이럴 · 데이터 · 퍼포먼스 · 커머스 · 리더십 · 커리어 — 에서 이어집니다.
