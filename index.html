문제 해결

대량조회 누락 → 해결

14일치를 한 번에 조회하면 데이터를 다 못 받아오는 문제가 있었습니다. 4일씩 나눠서 조회하고 중복만 제거하는 방식으로 바꿔서 전부 정상 수집되게 했습니다.

요청 제한 초과 → 해결

한 번에 너무 많이 요청하면 막히는 문제가 있었는데, 요청 간격을 조절하고 실패하면 자동으로 다시 시도하게 만들어 15만 건이 넘는 데이터도 누락 없이 수집했습니다.

로그인 정보 만료 → 해결

로그인 정보가 2주마다 만료되는 문제를, 하루 2번 자동 갱신하도록 만들어서 사람이 다시 로그인하지 않아도 되게 했습니다.

시트 데이터 밀림 → 해결

시트에 열이 하나 추가되면서 데이터가 밀려 잘못 들어가는 문제를 발견해 고치고, 빠진 날짜 데이터도 다시 채워 넣었습니다.
