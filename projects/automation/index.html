주요 성과
01 / 과제

배경과 과제

광고 운영과 커머스 업무에는 수집·확인·공유가 반복됐습니다. 경쟁사 자료를 모으는 일부터 매출·광고 보고, 재고 확인까지 자동화 범위를 넓혔습니다.

02 / 판단 기준

무엇을 기준으로 판단했나

공개된 사례에서는 광고 운영, 데이터 보고, 커머스 모니터링을 구분했습니다. 자동화 화면이 확인되는 경쟁사 광고 레퍼런스 수집·분류 사례를 대표 자료로 제시합니다.

03 / 실행 과정

직접 실행한 일

  1. 01

    광고 셋팅과 경쟁사 광고 레퍼런스 수집을 자동화했습니다.

  2. 02

    매출·광고 데이터 보고와 슬랙 기반 보고를 자동화했습니다.

  3. 03

    배송 지연 감지·CS 처리·재고 수량 확인·인플루언서 탐색·쿠팡 로켓 매출 및 재고 보고를 자동화 범위에 포함했습니다.

04 / 작업 화면

경쟁사 레퍼런스 수집·분류 화면

기존 포트폴리오에 공개된 실제 작업 화면입니다. 선택하면 확대할 수 있습니다.

공개된 자동화 업무 범주

  • 광고 자동 셋팅
  • 경쟁사 광고 레퍼런스 자동 수집
  • 매출·광고 데이터 보고 자동화
  • 배송 지연 자동 감지 · CS 자동 처리
  • 슬랙 기반 보고 자동화 · 광고 운영 자동화
  • 재고 수량 자동 감지
  • 인플루언서 자동 서치
  • 쿠팡 로켓 매출·재고 크롤링 자동 보고
05 / 결과

확인된 결과와 해석

기존 포트폴리오에는 총 15종 업무 자동화와 8개 공개 업무 범주가 기재되어 있습니다. 경쟁사 레퍼런스 수집·분류 화면이 공개되어 있습니다.

수치를 읽는 기준

공개 자료에는 전체 자동화 코드, 15종의 개별 명세, 절감 시간과 오류율 측정값이 없습니다. 따라서 시간 절감 비율이나 모든 작업이 완전 무인으로 운영됐다는 주장은 추가하지 않았습니다.
