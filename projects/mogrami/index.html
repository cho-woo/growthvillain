주요 성과
01 / 과제

배경과 과제

광고 영상, PPL, 공동구매는 집행 방식과 성과 집계 기준이 달랐습니다. 하나의 수치로 묶지 않고 각 콘텐츠의 결과를 확인할 필요가 있었습니다.

02 / 판단 기준

무엇을 기준으로 판단했나

개별 광고 소재는 메타 직접전환 기준으로, 협업 콘텐츠는 공동구매 또는 브랜디드 콘텐츠의 결과로 구분했습니다. 브랜드 월평균 지표와 개별 콘텐츠 성과도 나눴습니다.

03 / 실행 과정

직접 실행한 일

  1. 01

    광고 콘텐츠와 상세페이지를 기획하고, PPL·브랜디드 콘텐츠를 운영했습니다.

  2. 02

    광고 소재별 실제 영상과 집행 기준을 정리했습니다.

  3. 03

    노빠꾸탁재훈 공동구매, 이수근·김계정 채널 브랜디드 콘텐츠의 결과를 각각 공개했습니다.

04 / 광고 소재

실제 집행한 광고 소재

영상을 선택하면 재생됩니다. 프로젝트 영상에 소리가 있으면 배경음은 자동으로 작아집니다.

ROAS 164%노빠꾸탁재훈 · 공동구매(RS) ↗ROAS 288%이수근 채널 · 브랜디드 콘텐츠 ↗ROAS 170%김계정 채널 · 브랜디드 콘텐츠 ↗
05 / 결과

확인된 결과와 해석

브랜드 2026년 월평균 ROAS는 250%입니다. 공개된 개별 소재에는 메타 직접전환 ROAS 175%·광고비 4,000만 원이 기재되어 있습니다. 협업 콘텐츠 ROAS는 노빠꾸탁재훈 164%, 이수근 288%, 김계정 170%로 구분됩니다.

수치를 읽는 기준

288%는 이수근 채널의 개별 브랜디드 콘텐츠 수치이며 전체 브랜드나 모든 소재의 평균이 아닙니다. 공동구매(RS) 결과와 메타 직접전환 결과를 같은 기준으로 합산하지 않았습니다.
